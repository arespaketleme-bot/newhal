NewHal İlan API

Mersin Hal Kompleksi'ndeki ilanları kendi uygulamanızda, sitenizde ya da tablonuzda kullanın. Ücretsizdir, kayıt ve anahtar gerekmez.

Adres: https://newhal.com/api/v1
Biçim: JSON · Sınır: IP başına dakikada 120 istek · Tanım dosyası: openapi.json (Postman, Swagger vb. için)

İlan listesi

GET /api/v1/ilanlar

Yayındaki ilanları en yeniden eskiye, sayfa sayfa verir.

ParametreAçıklamaÖrnek
araBaşlık ve açıklamada arar. Birden çok kelimenin hepsi geçmeli. Türkçe harf farkı gözetmez.ara=limon
sayfaSayfa numarası (1'den başlar).sayfa=2
adetSayfadaki ilan sayısı, en fazla 100 (varsayılan 20).adet=50
siralamayeni (varsayılan), eski ya da begeni.siralama=begeni
vitrin1 ise yalnızca vitrindeki ilanlar.vitrin=1
resimli1 ise yalnızca fotoğraflı ilanlar.resimli=1
tarihtenBu tarihten sonra verilen ilanlar.tarihten=2026-11-20
▶ Dene: limon ilanları

Tek ilan

GET /api/v1/ilanlar/{no}

İlan numarasıyla (/api/v1/ilanlar/412) ya da kimliğiyle getirir. İlan yayından kalktıysa 404 döner.

Alanlar

AlanAçıklama
noSitede görünen ilan numarası (#412).
telefonlarMetinde geçen telefon numaraları, 0 ile başlayan 11 hane.
etiketYapay zekanın ilandan çıkardığı tür, ürün, miktar, fiyat ve yer. Yalnızca İlan Ajanı'nın bulduğu ilanlarda vardır, diğerlerinde null.
linkİlanın NewHal sayfası. İlanı gösterirken bu bağlantıyı vermenizi rica ederiz.

Kod örnekleri

Komut satırı

curl "https://newhal.com/api/v1/ilanlar?ara=domates&adet=10"

JavaScript

const r = await fetch('https://newhal.com/api/v1/ilanlar?ara=mandalina');
const { toplam, ilanlar } = await r.json();
ilanlar.forEach(i => console.log(i.no, i.baslik, i.link));

Python

import requests
r = requests.get("https://newhal.com/api/v1/ilanlar", params={"ara": "nakliye", "adet": 50})
for ilan in r.json()["ilanlar"]:
    print(ilan["no"], ilan["baslik"], ilan["telefonlar"])

Google E-Tablolar

E-Tablolar JSON'u doğrudan tablo yapmaz; düzgün tablo için Apps Script ya da bir JSON eklentisi kullanın.

Kurallar

  • İlanları gösterirken kaynak olarak NewHal'i ve ilanın link bağlantısını belirtin.
  • İlanlardaki telefon numaralarını toplu mesaj, arama ya da reklam için kullanmayın; ilan sahiplerinin izni yoktur.
  • Dakikada 120 istek sınırı aşılırsa 429 döner; Retry-After başlığındaki saniye kadar bekleyin. Cevaplar 1 dakika önbelleğe alınabilir.
  • Daha yüksek sınır ya da yeni alan ihtiyacınız için bize yazın.
